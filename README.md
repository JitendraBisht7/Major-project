# 🏠 Airbnb Clone

An Airbnb Clone web application that allows users to browse properties, view detailed listings, and book stays. This project is built to practice full-stack web development concepts and modern technologies.

---

## 🚀 Features

- User authentication (Sign up / Login)
- Browse property listings
- View property details with images
- Search and filter listings
- Book a property
- Host can add new listings
- Responsive design for mobile and desktop

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- CSS / Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
